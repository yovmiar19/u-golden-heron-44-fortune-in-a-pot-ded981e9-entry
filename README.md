# Fortune in a Pot

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9)
[![Node.js](https://img.shields.io/badge/node-22-green)](https://nodejs.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A one-line fortune written for a houseplant, as if the plant were the one having its future told. The program writes the fortune to `/output/entry.txt` — 80 characters, kind and funny, about the orange cat napping beside the pot.

> The orange cat will sleep beside you today, but do not trust his twitching tail.

## Run

```sh
node main.ts
```
