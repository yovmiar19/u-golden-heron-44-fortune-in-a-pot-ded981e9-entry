A one-line fortune written for a houseplant, as if the plant were the one having its future told. The keeper means well, but the tall man and his plastic watering can are loving it to death — the fortune warns the plant about exactly that. `main.ts` builds the line from two clauses (the omen, then the verdict) so the warning and its punchline stay in order.

> Beware the tall man with the plastic watering can; his affection is drowning you.

The fortune is 81 characters, a single line, and the program writes it byte-exact to `/output/entry.txt` with no trailing newline.

## Run

```sh
node main.ts
```
